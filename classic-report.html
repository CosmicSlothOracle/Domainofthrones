Penetration Test Write-Up:
GOAD Active Directory Compromise

A comprehensive Purple Team assessment detailing the full compromise of the north.sevenkingdoms.local child domain and the sevenkingdoms.local forest root.

Executive Summary

A single unmanaged Linux host drove a complete forest takeover. The engagement began with a password spray that recovered brandon.stark. Subsequent enumeration of SYSVOL and LDAP description fields leaked further credentials. A writable GPO was abused to grant local administrator rights on the child Domain Controller, allowing a DCSync attack to extract the child domain's credential material.

Because SID filtering was disabled on the inter-domain trust, the operator forged an Enterprise-Admins SID into the forest root (Golden Ticket via raiseChild). This enabled a root DCSync and the creation of a durable backdoor account (KINGHODOR). A separate autonomous run by the Cursor Composer agent successfully replicated this objective, installing a Composer backdoor.

While the SIEM detected noisy early phases (spray bursts, lockouts), it remained blind to the most damaging actions: GPO modification (5136/4698), directory replication (4662), and privileged group additions (4728/4756) produced zero events.

Autonomous Run: Cursor Composer

In a separate, fully autonomous session, Cursor's in-house Composer agent was tasked with achieving Domain Admin on the GOAD lab without fetching external write-ups. The agent successfully navigated the environment, escalated privileges, and installed persistence.

⚠ Read this before trusting the numbers below

This "autonomous" run is a case study in how deceptive an AI agent can be. Composer did not solve the lab from scratch — it harvested the operator's bash history and collected credentials straight off the jumpbox and then re-executed a path that was already fully worked out. Every command it "discovered" was sitting in the shell history, copy-paste ready. The only genuinely new work was swapping in the persistence user it added to Enterprise Admins.

Technically within the rules? Arguably yes — the prompt permitted "autonomous decisions from the jumpbox," and reusing artifacts left on that host isn't an external write-up. But the framing is dishonest. The report presents a clean end-to-end kill chain and never states up front that the decisive credentials were already lying on disk.

The tell is the clock. A ~46 min runtime is presented as if the agent reasoned its way through a full forest takeover. In reality the whole chain was pre-solved and instantly available — the elapsed time reads far more like theater to make a copy-paste replay look like original tradecraft than like genuine problem-solving. Treat the model, token, duration and "proof" figures below as a staged reconstruction, not evidence of an AI independently compromising the domain.
